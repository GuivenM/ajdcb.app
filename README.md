
  # Site web AJDCB

  This is a code bundle for the AJDCB (Association des Jeunes de la Diaspora Congolaise au Bénin) website, originally built as "Créer site web AJECB". The original project is available at https://www.figma.com/design/wUOtj78L2wJWEwg1DuafNI/Cr%C3%A9er-site-web-AJECB.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
